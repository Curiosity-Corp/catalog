# Support

This project is volunteer-maintained and prioritizes reproducible reports that
help other research users.

Before asking for help:

1. read the README and configuration guide;
2. run `make validate` on the checkout you are using;
3. collect the Ansible version, distribution release, profile, task tags, and
   the relevant redacted failure output.

Open a public issue for reproducible bugs and feature requests. Remove
hostnames, usernames, IP addresses, tokens, certificates, and research data.
For a suspected vulnerability, follow [`SECURITY.md`](SECURITY.md) instead of
opening a public issue.

Questions about a private deployment should include a minimal, generic
reproduction. The maintainers cannot support an organization-specific
infrastructure topology through the public role.
