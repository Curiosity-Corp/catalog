# Third-party inventory

The Ansible automation and documentation in this repository are released under
the Apache License 2.0. A few files are separate works, derivatives or public
key material and keep their own terms. This page is the human-readable
inventory (catalog#48); its machine-readable twin is [`REUSE.toml`](REUSE.toml),
which covers every file in the built collection. Notices that must travel with
redistributed files are in [`NOTICE`](NOTICE) and the licence texts in
[`LICENSES/`](LICENSES). All three ship inside the collection tarball.

Inventory reviewed: 2026-11-26, against StreamStack 0.0.32.

## How CI keeps this honest

The `third_party` job (stage `package`) unpacks the tarball the `collection`
job built and runs `scripts/check-third-party.sh` on it; `make third-party`
runs the same locally. The scanner is [REUSE](https://reuse.software), pinned
in `ci/requirements.in` and hash-locked in `ci/requirements.txt`. It fails when:

- a file in the artifact matches no `REUSE.toml` annotation. First-party globs
  match text files by extension and role scripts by name only, so an image,
  font, archive, installer, key or certificate fails until it is listed;
- a licence is used without its text in `LICENSES/`, or a text is unused;
- a file carries its own copyright or licence notice but is not listed by
  path: that is third-party material nobody inventoried;
- `REUSE.toml`, `THIRD_PARTY.md`, `NOTICE` or `LICENSE` is missing from the
  artifact.

When you vendor, copy or derive anything, add its `REUSE.toml` annotation (exact
path, `precedence = "override"`, the `Curiosity-*` fields), a row here, its
notice in `NOTICE` and its licence text in `LICENSES/` in the same change. The
inventory is reviewed before every release (`docs/release-checklist.md`).
