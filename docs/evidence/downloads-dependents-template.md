# Downloads and dependents log

An append-only log of registry measurements. Add a new dated entry each time; do
not edit an old one. If the registry does not expose a number, write "not
available", never an estimate.

Rule: do not state a threshold ("over N downloads", "used by N projects") unless
an entry below supports it with a source a reader can check.
